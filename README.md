# UraniumContaminationEra-II(铀污染时代 II)

> **定位声明:** 一款以「废土重建工业文明」为背景的 Minecraft 科技模组。
> 世界已毁于核战,旧时代的机器只剩废墟;玩家从拆解第一块铁皮开始,
> 历经 0 级手工、电力革命、气体化工、核能工业,直到锻造出工业文明的终极答案——**永恒币**。
>
> 本模组的设计哲学:**工业流程的完整性优先**。机器不是工作台合成的——是**蓝图 + 锤子**敲出来的;电压等级不符会瞬间击穿,功率过载 3 秒熔毁;气体真的会弥漫、泄漏、随风飘散。

## 〇、模组简介

| 项目 | 内容 |
|:---|:---|
| 模组 ID | `uraniumcontaminationeraii` |
| 显示名 | UraniumContaminationEra-II(UCE-II) |
| 背景 | 核战废土;世界生成时散布旧时代工业废墟,0 级阶段从「考古」开始 |
| 核心设计 | **三轴无限体系**:能量密度轴(CtI→CtV)/ 材料品质轴(纯度 1~5 级)/ 自动化深度轴(手动→量子自治) |
| 机器规模 | 20 个工程大类,原始构想 ~160 台 → 三轮筛选定稿 **104 台** |
| 成长阶段 | 0 级(无电力手动)→ 1 级(电力)→ 2 级(工业)→ 终局(永恒币) |

## 一、核心特性

| # | 特性 | 一句话说明 | 设计文档 |
|:---:|:---|:---|:---:|
| 1 | **蓝图搭建** | 选机型 → 放预览 → 填材料 → 锤子敲成型,104 台机器全部如此搭建 | §三 |
| 2 | **电力双判定** | 电压等级(CtI~V)判绝缘击穿,功率数值(Ct/s)判过载熔毁,两条规则独立执行 | §1.0 |
| 3 | **温度系统** | 配方温度门槛是硬条件;过热降效 → 卡顿 → 强制停机;区块级环境温度影响建厂选址 | §十二 |
| 4 | **气体系统** | 19 种气体,逐格扩散、风动偏移、围合空间识别;泄漏治理三选一:密封/收集/排放 | §十三 |
| 5 | **纯度体系** | 材料纯度 1~5 级(灰绿蓝紫金),精馏塔/区域熔炼逐级提纯 | §13.6 |
| 6 | **物流带** | 传送带 + 四级电机,传动杆叠加提速,超载降速 | §四 |
| 7 | **机器维护** | 耐久随运行消耗;锤子/材料/无人机三种维修;**副产强制循环**(无垃圾桶) | §3.5/§10.6 |
| 8 | **装备线** | 科技工程师眼镜 → 体征监测器 → 外骨骼框架 → 动力装甲(CtII→CtIV) | §九 |
| 9 | **终极目标** | 锻造核心铸造永恒币:定制矿脉 / 机器进化 / 开启奇点维度 | §8.4 |

## 二、玩法演进时间线

```text
0级·考古时代 ── 废墟拆解 → 碎石锤 → 矿粒 → 第一批金属锭
     │                (手动操作消耗双倍饥饿值)
     ↓ 造出 CtI 马达与基础电路板
1级·电力时代 ── 水力发电机 → 拉线输电 → 第一台机器通电
     │
     ↓ 蓝图搭建,工业体系铺开
2级·工业时代 ── 78 台机器、物流带、核燃料链(RBMK 反应堆)
     │
     ↓
3级·精密时代 ── 气体管道化、纯度 5 级、PLC 流水线、中央控制台
     │
     ↓
终局·永恒时代 ── 液氦超导、锻造核心、永恒币、奇点维度
```

## 六、项目结构

```text
├── UraniumContaminationEraII.java   # 主类(MOD_ID 入口)

```
